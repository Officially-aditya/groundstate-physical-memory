# Groundstate demo talk track

Use this as the spoken/captioned structure for the hackathon demo. The point is to make the familiar shell and the distinct product primitive obvious in the first 20 seconds.

## 0:00–0:10 — Frame the difference

“Git and modern agent tools preserve what happened to code. Groundstate preserves what happened to a physical workspace. The familiar project navigation is intentional; the records inside it are evidence-backed physical states, not source files.”

## 0:10–0:25 — Show the live product

Open **Workspace** mode on the hosted Cloud Run URL. Click **Capture evidence**, add the operator note, and show the four steps: Capture → Reconcile → Approve → Follow up. Call out the live Cloud Run badge.

## 0:25–0:42 — Show the agent working

Submit the observation. Point to the semantic diff: A17 is missing, B02 remains visible, and C-01 is running. Explain that Gemini 3.5 Flash Lite returns a typed claim with confidence; the agent asks for one human anchor instead of silently overwriting history.

## 0:42–0:55 — Show the physical-world primitive

Choose **It’s B02**. Show the revision view: the old belief remains in the log, A17’s timer is restored, and B02 becomes the centrifuging sample. This is the differentiator: corrections travel through dependent physical assumptions.

## 0:55–1:05 — Show autonomous continuity

Open **Automations** and use the wake-up control. Explain that Pub/Sub reopens an expected physical transition when evidence does not arrive.

## 1:05–1:15 — Optional judge-safe replay

Switch to **Demo replay** only if a deterministic walkthrough is useful. Say explicitly that replay mode is a fixture for evaluation; Workspace mode is the live product surface.
